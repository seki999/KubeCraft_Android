## 尚未完成的验收与优化

- 真机/模拟器 Compose UI、SQLite 重开、APK 升级保档、手机和平板不同字体/键盘布局验收。
- 性能基准、无障碍读屏、复杂大集群负载测试。
- 正式发布 keystore 签名。Release 默认生成 unsigned APK，不在仓库存放私钥。
- YAML 是固定示例结构；云场景、StatefulSet、探针与资源限制是明确的教学子集。
- 进度每次修改串行排队写入 SQLite；极端强杀可能丢失尚未提交的末尾操作。
- 结算与经验有状态动画，仍需设备视觉 QA，不能声明画面已无瑕疵。
