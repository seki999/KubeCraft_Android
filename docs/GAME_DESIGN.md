# KubeCraft — Kubernetes 云端帝国

面向 Android 10+ 的离线模拟经营学习游戏。Maya 解释技术，Leo 提出业务需求，K8-Bot 展示集群反馈。玩家不是回答选择题，而是改变集群的期望状态、推进逻辑时钟、观察调度和控制器的结果。

## 当前可玩闭环
首页 → 章节地图 → 剧情任务 → 终端提交操作 → 城市观察 → 状态断言 → 技术复习 → 结算与下一关。自由城市与课程共用纯 Kotlin reducer。

前十关依次教授 Worker、独立 Pod、Pending、健康节点调度、Deployment、ReplicaSet 扩容、自愈、缩容、滚动更新、回滚。每关具有独立初始状态、剧情、目标和提示。10 章 50 关均有可执行的初始状态、独立剧情、目标与命令实践。高级场景使用受控教学子集，逐关边界见 IMPLEMENTATION_STATUS.md。

## 评分
完成状态目标 60；资源效率最多 15（已请求 CPU / 节点容量，以 25% 利用率作为满分基准）；操作效率最多 10（超出 JSON idealActions 后逐步扣分）；术语短答复盘 10；未请求提示 5。术语短答按关卡英文答案（忽略大小写和空格）验证，不作为唯一通关条件。推进 tick 不计操作次数。一星 60–74，二星 75–89，三星 90–100。每次会话只能领取一次奖励；重玩累积完成次数，最高分不下降。

## 交互与适配
手机上方保留城市，底部打开任务、终端、YAML、状态面板；宽度达到 840dp 后使用左右分栏。面板支持滚动和 imePadding。Canvas 展示等距节点基座、Pod 状态和实际 Service 端点流量；逻辑时钟由玩家推进。设置保存深色主题、字体比例、动画和慢速偏好。

## 边界
这是教学模拟而非生产 Kubernetes。不存在 shell、网络集群、Docker 或真实云 API。没有网络权限。高级云课程未开放，不会产生真实费用。
